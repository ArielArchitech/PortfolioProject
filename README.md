
# Ariel Feldman — Portfolio Website

### A personal portfolio website showcasing my projects, skills, and experience as a Full Stack Developer. 
### Built with clean, semantic HTML, modern CSS, and vanilla JavaScript — no frameworks, no dependencies beyond what's needed.

## 🌐 Live Demo View Portfolio → ✨ Features

Responsive design — mobile-first layout with hamburger menu, scales gracefully up to 1400px+
3D rotating project carousel — CSS transform-style: preserve-3d with 8 project cards
Project modals — click any card to open a detailed overlay with live demo and GitHub links
Floating label contact form — integrated with EmailJS for serverless email delivery
Smooth scroll navigation — fixed header with anchor links and scroll-margin offsets
CSS-only hamburger animation — no JavaScript required for the menu toggle
